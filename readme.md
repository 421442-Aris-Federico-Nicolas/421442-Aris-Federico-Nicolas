## ✦ Sobre mí

Soy estudiante de **Tecnicatura en Programación en la UTN** y desarrollador Full Stack en formación, interesado en crear aplicaciones modernas, escalables y bien estructuradas.

Durante mi formación participé en proyectos individuales y colaborativos que me permitieron trabajar con arquitecturas de microservicios, desarrollo de APIs REST, aplicaciones web y herramientas de integración.

Me interesa especialmente el desarrollo backend con Java y Spring Boot, sin dejar de lado el frontend y la experiencia completa de una aplicación.

**Actualmente estoy enfocado en:**
- Desarrollo backend con Java y Spring Boot.
- Aplicaciones frontend con Angular y TypeScript.
- Diseño e integración de APIs REST y microservicios.
- Buenas prácticas de desarrollo y trabajo colaborativo con Git.
