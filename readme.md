## Sobre mí

Soy estudiante de **Tecnicatura en Programación en UTN** y desarrollador Full Stack en formación.

Me interesa diseñar y desarrollar aplicaciones completas, desde la lógica de negocio y las APIs hasta las interfaces que utilizan las personas.

En mis proyectos académicos y personales estoy incorporando experiencia en:

- Desarrollo backend con Java y Spring Boot.
- Aplicaciones frontend con Angular y TypeScript.
- Arquitecturas de microservicios y APIs REST.
- Bases de datos, integración de servicios y Docker.
- Trabajo colaborativo con Git, Pull Requests y revisiones de código.
