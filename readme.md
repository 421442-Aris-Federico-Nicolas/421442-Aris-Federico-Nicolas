```bash

```

Soy estudiante de la **Tecnicatura en Programación de la UTN** y desarrollador Full Stack en formación, de Córdoba, Argentina.

Me apasiona el desarrollo de software, la arquitectura backend y la creación de aplicaciones web escalables.

- Bases de datos relacionales y orientadas a grafos.
